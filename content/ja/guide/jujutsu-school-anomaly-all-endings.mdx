## 通常・バッドエンディングの攻略手順

初期の分岐ルートは、異変パターンの見分け方を学ぶ訓練場となります。環境変化の見落としは手痛いペナルティとなりますが、これらの早期結末を体験することで空間ギミックの仕組みを深く理解できます。

### エンディング1：Trapped in the Loopの発生手順

この結末は、細かな違和感の報告を怠ったり、通常の廊下の構造を誤って異変と判定したりした場合に発生します。

1. 中央中庭の扉から通常の巡回を開始する。
2. 提灯のちらつきや掛け軸の文字の反転など、視覚的変化を無視して廊下を進む。
3. 誤った報告や方向転換の失敗を連続で3回重ねる。
4. 廊下の突き当たりにある補強された非常口の敷居を越えようとする。
5. 非常口が完全にロックされ、扉が消失した廊下1へループして戻される。

### エンディング2：Consumed by Cursesの発生手順

受動的なループ失敗とは異なり、この結末には能動的な環境ハザードが関係します。プレイヤーの検証によると、深夜のサイクルマーカー以降は攻撃的な怪異の出現率が上昇します。

* 教室の扉が半開きになっている状態で、3階の廊下に進入する。
* 浮遊する黒い影の怪異に遭遇した際、視線を逸らさず直視し続ける。
* 浄化の鈴を使用せず、影のゲージを完全に消耗させる。
* 画面が砂嵐に切り替わり、暗黒の運命実績が解除される。

## グッドエンディング「Barrier Restoration」の解放方法

「Barrier Restoration（結界修復）」エンドを達成するには、単なる回避から積極的な儀式遂行へと立ち回りをシフトする必要があります。逃げ回るだけでなく、校内の危険区域に散らばる4つの結界符を確保しなければなりません。

準備段階として校内マップを把握し、生還のタイミングを合わせるために[Steam Community Guides](https://steamcommunity.com)の詳細な解説などを参考に安全なルートを構築しておきましょう。

まず巡回を開始する前に、1階の祠を調べます。木製の香炉を手に取り、祭壇に捧げると「Talisman Compass（お札の羅針盤）」が出現します。この羅針盤は、未起動の結界符から3メートル以内に近づくと脈動します。

グッドエンドを達成するための手順は以下の通りです：

1. **北の結界符の発見:** 2年B組の黒板の裏にあります。机が後方にズレているサイクルでのみ出現します。
2. **南の結界符の回収:** 管理棟階段付近の床下にあります。提灯の明かりを点けずに影の追跡者をやり過ごす必要があります。
3. **東の結界符の浄化:** 中庭の外壁にある鐘に貼り付けられています。鐘の音が3回ではなく2回鳴った時のみ干渉してください。
4. **西の結界符の点火:** 化学室の炉の中にあります。職員室の机から入手できる浄化のマッチを使用します。
5. **最終手順:** HUD上に4つの結界符がすべて点灯した状態でExit 0へ向かい、結界陣を発動させます。

| 結界符の名称 | 部屋の場所 | 必要アイテム | 回収時の危険要素 |
| :--- | :--- | :--- | :--- |
| 北の符（風） | 2年B組 | チョーク | 机の激しい振動 |
| 南の符（地） | 管理棟階段 | 結界の鈴 | 踊り場を徘徊する盲目の追跡者 |
| 東の符（水） | 中庭の鐘 | 浄化の水 | 歪んだ鐘の音による誘惑 |
| 西の符（火） | 化学室 | 浄化のマッチ | 有毒な煙の発生 |

結界の修復に成功すると、学園に漂う負のエネルギーが完全に祓われ、夜明けのシークエンスと共にサイクルが終了します。

## 隠しトゥルーエンド「The Ancient Pact」の解放方法

**jujutsu school anomaly all endings**の中で最も到達困難な結末であり、完璧な観察力と複雑な遺物集めを同時にこなす必要があります。**jujutsu school anomaly all endings**の真の終焉を迎えるには、8連続の廊下で報告ミスを一切出さず、3つの呪われた破片を収集しなければなりません。

```
遺物1（引き裂かれた指の戒め） ──┐
遺物2（ひび割れた翡翠の器） ────┼──> 地下の秘密祭壇 ──> トゥルーエンド
遺物3（忘れ去られた学生証） ────┘
```

3つの遺物は毎周回出現するわけではありません。ルート進行を破綻させることなく、特定の環境異変を意図的に維持した状態でのみ姿を現します。

* **遺物1（引き裂かれた指の戒め）:** 廊下3にて、展示ケースの一番下の棚を確認します。天井の電灯が完全に消灯している場合のみ実体化します。
* **遺物2（ひび割れた翡翠の器）:** 廊下5にて、泣いている肖像画をすぐには報告しないでください。引き返す前に額縁の底部を調べて破片を回収します。
* **遺物3（忘れ去られた学生証）:** Exit 0の下にある隠し地下の入口にあります。これまでに2つの遺物を所持している場合のみ、床の格子が操作可能になります。

| フェーズ | 必要な行動 | 失敗条件 | 報酬／状態 |
| :--- | :--- | :--- | :--- |
| フェーズ1 | サイクル1～4をノーミスで突破 | 異変の判定を誤る | 遺物1が消滅 |
| フェーズ2 | 廊下5で翡翠の器を回収 | 額縁の前を素早く通り過ぎる | 器が完全に破損 |

地下の祭壇に3つの遺物をすべて捧げると、空間の歪みを生み出していた元凶との対峙が発生し、物語の真の結末を迎えることができます。

## 最重要の異変と対処法

不意打ちによるゲームオーバーを防ぎ、**jujutsu school anomaly all endings**を効率よく解放するためには、異変を素早く察知することが何よりも重要です。異変は大きく分けて視覚、聴覚、空間構造の3つに分類されます。

* **わずかな視覚的異変:** 床板の変色、ポスターの左右反転、時計の文字盤の狂い、影の消失など。確認したら直ちに直前の扉へ引き返してください。
* **明確な聴覚的異変:** 壁の内部から聞こえる規則的なノック音、逆再生される校内チャイム、足音の反響。光源を消し、5秒間静止してから移動してください。
* **空間構造の歪み:** 無限に続く廊下、扉の高さの変化、側面の出口の消失。直ちに来た道を引き返してください。

| 異変の兆候 | 異変のカテゴリ | 脅威度 | 必要な対処法 |
| :--- | :--- | :--- | :--- |
| 時計の針が反時計回りに回転 | 視覚 | 低 | 振り返り、前の廊下へ戻る |
| 1秒遅れて背後から足音が響く | 聴覚 | 中 | 移動を停止し、明かりを消す |
| ロッカーが激しく振動する | 物理 | 高 | 反対側の壁沿いをしゃがみ歩きで進む |
| 白いお札が赤いお札に変化 | 超常現象 | 極大 | 直視せず、ゆっくりと後退する |
| ドアノブから黒い液体が滴る | 環境 | 致命的 | 触れずに別の迂回ルートを取る |

これらの合図を即座に見抜くことで、進行中のデータを守り、厳格な条件が課されるエンディングへの挑戦時に無駄なリトライを減らすことができます。

## よくある質問（FAQ）

### 『Jujutsu School Anomaly』のエンディングは全部でいくつありますか？
主に5つの結末が存在します。バッドエンド2種（Trapped in the Loop、Consumed by Curses）、通常ニュートラルエンド1種（Safe Exfiltration）、グッドエンド1種（Barrier Restoration）、そして隠しトゥルーエンド1種（The Ancient Pact）です。

### 1つのセーブデータで最も早く全エンディングを回収する方法は？
最初に隠しトゥルーエンドの達成を目指すのが最善です。ミスが許されないトゥルーエンドに挑む過程で全異変のパターンが自然と身につくため、その後のバッドエンドやニュートラルエンドの回収が非常にスムーズになります。

### トゥルーエンド挑戦中に報告ミスをした場合、挽回は可能ですか？
不可能です。地下祭壇への通路を開くには、周回を通して完全にノーミスで異変を処理する必要があります。一度でも異変を見落としたり誤報告したりした場合は、廊下1からやり直す必要があります。
