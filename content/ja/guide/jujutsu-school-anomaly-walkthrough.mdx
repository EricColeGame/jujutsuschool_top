## 基本システムとループルールの理解

本作の核となる目的は、パターン認識と進行方向の的確な判断です。プレイヤーは、黄昏に包まれた無人の呪術キャンパスで目覚め、閉ざされた時間ループに閉じ込められています。出口の門へ進むには、同一に見える廊下の区画を通り抜けながら、「異変」と呼ばれる霊的な異常がないか周囲の環境を入念に観察しなければなりません。

廊下が完全に正常であれば、非常口サインの先へと直進します。ほんの僅かでも何らかの異変に気づいた場合は、即座に振り返り、入ってきた入り口の扉から戻る必要があります。正しい判断を下すごとに進行度カウンターがゼロに向かって進みますが、判断を誤ると進行度は「ループ8」までリセットされます。この体系的な呪術学校の異変攻略ガイドに従うことで、呪われた存在に不意を突かれる前に、本能的なスキャンリズムを身につけることが可能です。

| アクショントリガー | 環境の状態 | プレイヤーの対応 | 失敗時の結果 |
| :--- | :--- | :--- | :--- |
| 正常な区画 | 異変は検知されず | 奥の出口へそのまま直進する | カウンターがループ8にリセット |
| 微細な異変 | 空間、視覚、または音響の変化 | 180度反転して入り口から引き返す | カウンターがループ8にリセット |
| 能動的脅威 | 敵対的な影や追跡してくる実体 | ダッシュせずに即座に引き返す | 即死 / 挑戦の完全リセット |
| 境界セーフゾーン | 提灯が点灯、カウント減少 | 境界の張り紙を確認して前進 | リスク最小 / チェックポイント設定 |

最大の敵は「観察疲労」です。扉から扉へと闇雲に駆け抜けるのではなく、新しく生成された区画の開始地点で必ず立ち止まってください。視界を左から右へとゆっくり動かし、ポスター、ドアの表記、天井のファン、照明器具などをベースラインの配置と照合しましょう。

## 異変カタログ一覧と検知のポイント

学校敷地内の異変は、細かな装飾の変化から、現実を歪める致死的な現象まで多岐にわたります。広範なコミュニティ報告によると、心霊現象は主に視覚的な歪み、聴覚的な幻覚、空間的な異常という3つの感覚的分類に分けられます。

この呪術学校の異変攻略フェーズでは、索敵プロセスをスムーズにするため、異変を3つの脅威度ティアに分類しています。攻撃的な現象の近くに留まると即座にゲームオーバーとなるため、高脅威度の異変には特に警戒を払ってください。

| 分類 | ゲーム内での主な出現例 | 脅威レベル | 正しい対応 |
| :--- | :--- | :--- | :--- |
| **視覚 - 装飾** | ポスターの文字変化、逆さまのお札、下駄箱の靴の消失 | 低 | 入り口から引き返す |
| **視覚 - 実体** | 呪われたマネキン、障子に映る動く影、上下逆さまの学校肖像画 | 高 | 引き返す。直視を維持しないこと |
| **聴覚** | 響き渡る鈴の音、逆再生の読経、背後から近づく足音 | 中 | 音源を確認したのち直ちに引き返す |
| **空間 / 建築** | 廊下の伸縮、出口扉の消失、教室の窓から見える重力反転 | 致命的 | 即座に引き返す。歪んだ空間に入らないこと |
| **致死性実体** | 浮遊する赤いお札の霊、猛ダッシュしてくる影の実体 | 即死級 | 振り返り、通常の歩行速度で退避する |

視覚的なチェックは、常に教室の掲示板から始めるのが鉄則です。通常時、掲示板には4枚の部活動の案内と中央のキャンパスマップが貼られています。もしチラシに目のシンボルが描かれていたり、文字が黒く塗りつぶされていたり、血のような墨汁が垂れていたりした場合、その区画は汚染されています。

## 全セクター対応：呪術学校の異変ステップバイステップ攻略

学校の敷地内を安全に進むには、廊下のループを4つの独立した観察セグメントに分割する必要があります。この戦術的な呪術学校の異変攻略ガイドでは、各ゾーンを体系的に分解し、どのような環境の変化も見落とさないように解説します。

```
[入り口の境界] ──> [下駄箱＆掲示板] ──> [教室の窓際] ──> [職員室＆神社の出口]
```

### 1. 入り口の境界と下駄箱エリア
新しい区画に入った瞬間、足元のマットと生徒の下駄箱を確認してください。通常の下駄箱エリアは、木製の扉が閉まり、真鍮の名札が綺麗に並んでいます。ここでの異変には、開いたロッカーから黒いお札が浮かび上がっている、靴のつま先が逆を向いている、4番の下駄箱の下に血だまりができている、などが挙げられます。

### 2. 廊下中盤の教室の窓
無人のオカルト研究室のガラス仕切りに沿って進む際は、室内の机に注意を払ってください。普段は誰もいない部屋ですが、異変が起きると机が天井に向かって積み上がっていたり、黒板を向いた黒い人影が出現したりします。窓ガラスに映る反射も確認しましょう。自分のアバターの影が動きと一致しない、あるいは首だけをこちらに向けている場合は、直ちに引き返してください。

### 3. 職員室と連絡掲示板
ループの4分の3ほど進むと、職員室の付近で廊下の幅が広がります。[Steam Community hub](https://steamcommunity.com/) を含む主要なゲームコミュニティで共有されているガイドでも、このセクションの上にある天井の照明を確認することの重要性が頻繁に強調されています。蛍光灯が点滅し、ジーという環境音が響いている場合、音響・空間系の異変が発生しているサインです。

| 廊下ゾーン | 主なチェック項目 | 危険な異変の警告サイン |
| :--- | :--- | :--- |
| **ゾーン1: 下駄箱エリア** | 靴の向き、ドアの取っ手、足元マット | ロッカーの扉が外れている、靴が外を向いている |
| **ゾーン2: 教室前廊下** | 机の数、窓の反射、影の角度 | 浮遊するチョーク、黒板を向いて立つ人影 |
| **ゾーン3: 職員室スペース** | 時計の時刻、掲示物のチラシ、非常電話 | 時計が反時計回りに進む、受話器が外れている |
| **ゾーン4: 出口境界** | 出口の提灯の色、非常口サインのピクトグラム | 提灯が緑ではなく赤に点灯、走る人物が消えている |

## 生存戦術と即死トラップの回避法

すべての異変が受動的な謎解きとは限りません。特定の条件下では、廊下を能動的に徘徊する呪霊も存在します。呪術学校の異変攻略において生き残る術を極めるには、学校に巣食う呪いの実体がプレイヤーの動き、移動ペース、視線にどのように反応するかを理解する必要があります。

まず、常時ダッシュしたい衝動を抑えてください。走れば各ループの所要時間は短縮されますが、足音のボリュームが大きくなり、角を曲がった先に即死トラップがあった際の反応時間が削られます。歩行を維持することで視界が安定し、壁の歪みや天井タイルのズレといった空間異変にも即座に気づくことができます。

| 脅威タイプ | 行動パターン | 主な危険性 | 回避プロトコル |
| :--- | :--- | :--- | :--- |
| **赤布の怪** | 廊下の最奥に出現し、ゆっくり前方へ浮遊 | 直接接触すると即死 | 即座に180度反転し、入り口へ歩いて戻る |
| **囁く鐘** | 大きな鐘の音が響き渡り、廊下の明かりが消灯 | 空間の混乱と方向感覚の喪失 | 足を止め、音の方向を確認してから引き返す |
| **反転した鏡像** | 教室のガラス越しに見つめ、遅れて足音を真似る | 近づくと教室内に閉じ込められる | ガラスに触れず、直ちに進行ルートを逆走する |
| **床のお札** | 廊下の床一面に呪われた紙のお札が敷き詰められる | お札を踏むと即座にゲームオーバー | 汚れていない綺麗な床タイルだけを踏んで戻る |

急激な明暗の変化や画面の四隅が暗くなるヴィネット効果が発生した際は、その場で立ちすくまないでください。画面が暗くなるのは、その区画に敵対的な実体が出現した証拠です。冷静さを保ち、壁や障害物に引っかかることなく滑らかにUターンすることが、連続クリアを維持する秘訣です。

## 隠しエンディングと真・祓魔ルートの到達手順

ループ0に到達することは、通常のシミュレーションから脱出するための最低条件に過ぎません。すべての結末をアンロックするには、呪術学校の異変攻略エンドゲームチェックリストに従い、特殊条件を満たしてキャンパスの敷地を浄化し、真の祓魔（ふつま）エンディングへと到達しましょう。

コミュニティの検証データによると、真の結末を迎えるには、1回の挑戦中に一度もループリセットを引き起こすことなく、8つの特別な高難度異変を特定する必要があります。

| エンディング名 | 解放条件 | 難易度 | 最終遭遇タイプ |
| :--- | :--- | :--- | :--- |
| **通常脱出** | ナビゲーションミスゼロでループ0に到達 | 普通 | 鳥居のある中庭からの無事な脱出 |
| **呪縛ループ** | ループ1で誤った道を選択 | 簡単 | 永遠に囚われるバッドエンド演出 |
| **真・祓魔** | 5つの特別な結界札をすべて発見し、本堂を浄化 | 難関 | 祭壇での制限時間付き浄化シークエンス |
| **虚ろなる学徒** | 一度もダッシュを使用せずに通しクリア | 熟練者 | 隠された手記の伝承が解放される静かな脱出 |

「真・祓魔」ルートを確定させるには、職員室の戸棚の中に貼られている金色の結界札を見逃さないようにしてください。発見後、連続した挑戦の中で5つすべてに干渉すると、通常のループ境界の隣に別の地下階段が出現し、果てしない廊下を完全にバイパスできるようになります。

## よくある質問（FAQ）

### 呪術学校の異変の1回のフルランにはどのくらい時間がかかりますか？
ミスなく順調に進んだ場合、探索ペースにもよりますが通常15〜30分程度でクリアできます。ただし、建物の基本構造を把握し、異変の出現ポイントを覚えるまでの初見プレイでは、45〜60分程度かかることが一般的です。

### 異変が自分のすぐ背後に出現した場合はどうすればよいですか？
廊下の中ほどまで進んだ際に入り口の境界に異変が出現しても、慌てる必要はありません。その異変が能動的な敵対実体なのか、それとも静止した空間異常なのかを確認してください。戻るべき入り口を敵が塞いでいる場合は、感知範囲の外で待機します。敵対的な亡霊は徐々に消滅するか、決まった巡回ルートを移動するため、安全にすり抜けることができます。

### 廊下が正常に見えたのにループカウンターがリセットされたのはなぜですか？
微細な異変は、意図的に見落としやすく作られています。特によく見落とされるのは、非常口の誘導標識のピクトグラムが逆向きに走っている、時計の針が逆回転している、天井タイルの模様がわずかに変わっているといった細微な変化です。カウンターがリセットされた場合は、直前にいたセクターを記録しておき、次の周回でそうした細かな箇所を重点的に再確認してください。
