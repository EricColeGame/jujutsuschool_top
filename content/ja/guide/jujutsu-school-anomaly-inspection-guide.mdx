## 基本システムと調査サイクルの理解

異変が発生する夜間シフトを生き抜くための本質は、一切の異常がない「基準（ベースライン）環境」を正確に記憶し、直線のセクターを通過する際に差異を見つけ出すことにあります。このループ型サバイバルゲームでは、プレイヤーは何もない控室からスタートし、指定された廊下を進みます。セクターが完全に正常であれば、そのまま出口の扉を通って前進します。微小な怪異であっても発見した場合は、直ちに反転して入口の扉から引き返し、異変を記録して進行カウンターを進める必要があります。

```
[開始地点] ---> [廊下・部屋の調査] ---> [異変なし？ そのまま進む]
                                 ---> [異変あり？ 直ちに引き返す]
```

異変が発生しているのに出口を通過したり、完全に正常な廊下で引き返したりするミスを犯すと、シーケンスカウンターはゼロにリセットされます。この再帰的なループを脱出するには、連続して完璧な判断を下し続けなければなりません。

## 校内の異変に関する完全分類

敷地内に現れる異変は、すべてが同じ形で現れるわけではありません。熟練の調査員は、害のない外観のバグからプレイヤーを追跡・殺害する能動的な実体まで、異変を明確な脅威プロファイルに分類しています。

### 1. 視覚的・構造的変化
学校の形状、看板、装飾などに生じる静的な変化です。障子に貼られた書道の掛け軸が上下反転している、何もない壁に余分な引き戸が出現する、壁の武器ラックに掛かる木刀の角度が変わっているなどの例が挙げられます。命に関わる危険はありませんが、小走りで急いで駆け抜けようとすると極めて見落としやすい異変です。

### 2. 環境および照明の歪み
照明の変動は、空間の雰囲気を一変させる代表的な異常です。提灯の明かりが血のような赤色に染まる、蛍光灯が不気味に明滅する、突如として完全な停電に陥る、光源とは逆方向に影が伸びるなどの現象に遭遇することがあります。特定のループでは、廊下全体が足首ほどの濁った水や呪気の瘴気に覆われることもあります。

### 3. 音響現象
音の異変を見極めるには、耳を澄ませる警戒心が欠かせません。資料室の書架の奥からくぐもった詠唱が聞こえる、自身の歩調と一致する濡れた足音が追随してくる、深夜にもかかわらず学校のチャイムが鳴り響く場合、視界が完全に正常であっても異変が存在します。

### 4. 実体化と敵対的実体
最も危険な異変は、呪われた存在が実体化するケースです。廊下の突き当たりに微動だにせず立つ黒い人影、プレイヤーを目で追う浮遊する能面、視線を外した瞬間に突進してくる敵対的な怪異などが現れる可能性があります。

| 異変クラス | 出現頻度 | 視認難易度 | 即時対応策 |
| :--- | :--- | :--- | :--- |
| **物体の変位** | 高頻度 (~40%) | 中〜高 | 基準状態と照合。確認できたら引き返す。 |
| **文字・記号の反転** | 高頻度 (~25%) | 高 | 護符、結界の封印、壁の掲示板を確認。 |
| **照明の異常** | 中頻度 (~15%) | 低 | 異常な色合いに気づいたら即座に反転。 |
| **聴覚的反響** | 中頻度 (~12%) | 高 | 3秒間足を止め、環境音を確認する。 |
| **敵対的実体** | 低頻度 (~8%) | 極めて低（明確） | 近づかないこと。前の扉までダッシュで撤退。 |

当**呪術学校の異変調査ガイド**の分類マトリクスを参照することで、一目で分かる明白な怪異から、壁のテクスチャの微細な変化まで確実に察知できます。

## ゾーン別・段階的調査プロトコル

安定してクリアを達成するには、廊下の巡回を4つの体系的な視覚チェックに分割してください。この順番通りの確認を行わずに廊下の中央を走り抜けることは厳禁です。

```
ゾーン1：入口の境界＆天井
   ↓
ゾーン2：目線の高さの設備（障子、張り紙、掛け軸）
   ↓
ゾーン3：床板、影、足音
   ↓
ゾーン4：最奥の出口扉＆遠景の構造
```

### ゾーン1：入口の境界＆天井
引き戸が開いて新しいエリアに入った瞬間、敷居のところで直ちに足を止めてください。天井の梁を見上げます。呪われた学校では、首吊り縄、反転した垂木、梁から垂れ下がる血を流すお札などが頻繁に隠されています。天井に異常がなければ、頭上すぐの光源を確認します。

### ゾーン2：目線の高さの壁と書道
廊下へ3歩進みます。壁の掛け物に合わせて視点を左から右へとゆっくり動かします。特に以下の点に注意してください：
- 結界の垂れ幕に書かれた漢字（筆順や字形の反転を確認）。
- 門限に関する掲示板の通知内容。
- 儀礼用の木製短剣が収められたガラスケース。

### ゾーン3：床面と幅木
視線を下げ、畳や木の床板を点検します。異常な血痕、下駄の不自然な散乱、家具の下の影の欠落、磨かれた木床の歪んだ反射がないか注意深く観察します。

### ゾーン4：最奥の境界と出口扉
出口の門をくぐる前に、目の前にある扉の枠を確認します。ドアノブの高さ、注連縄（しめなわ）の有無、そして非常口サインが正規の緑色に光っているか、それとも異常な赤色で点滅していないかを監査します。

| セクター点検表 | 重点監査対象 | 主な異変パターン |
| :--- | :--- | :--- |
| **道場の廊下** | 木人、武器ラック、天井の梁 | 予備の木刀が増えている、血を流す木人、反転した垂木。 |
| **寮の廊下** | 部屋番号の銘板、下駄箱、通路のマット | 部屋番号の入れ替わり、手が生えている開いたロッカー、マットの消失。 |
| **資料館・書庫** | 巻物の棚、吊るされたお札、硯机 | 浮遊する巻物、机の脚の欠損、オーディオからの囁き声。 |
| **中庭の回廊** | 石灯籠、桜の枝、玉砂利 | 中央の石灯籠の消火、空中で静止した花びら。 |

本**呪術学校の異変調査ガイド**に記載されているゾーン別の手順を徹底することで、連勝記録を台無しにする不用意なミスを排除できます。

## 高度な検知戦略とコミュニティの秘訣

[Steam コミュニティのホラーハブ](https://store.steampowered.com/category/horror)などのプラットフォームにおいて、異変検知ゲームをやり込んでいる熟練プレイヤーたちは、連勝維持と生還の成否を分ける細かな仕様を記録しています。

### 映像と音声設定のキャリブレーション
- **視野角（FOV）：** FOVは85から90の間に設定してください。視野角を広げすぎると画面端のテクスチャが引き伸ばされ、サイズ変化系の異変を正確に見極めるのが困難になります。
- **明るさ / ガンマ値：** 開発者が推奨するデフォルト設定を維持してください。不自然に明るくすると繊細な影の異常が白飛びし、反転した影などの異変が見えなくなります。
- **オーディオイコライザー：** ヘッドセットのソフトウェアで中高音域を強調すると、背景の環境ノイズから微かな木床の軋みや布の擦れる音を聞き分けやすくなります。

### 「3秒静止」ルール
多くのプレイヤー報告において、廊下の中間地点で完全に足を止め、丸3秒間静止することが強く推奨されています。いくつかの動的な異変はプレイヤーが静止した時にのみ発生するか、絵画の目がゆっくり開くような遅延アニメーションを伴うためです。

| よくある偽陽性（正常演出） | 本物の異変の兆候 | 推奨される行動 |
| :--- | :--- | :--- |
| 通常のちらつく提灯 | 光が完全に青や赤に変色 | 異変とみなし引き返す。 |
| 壁テクスチャのわずかなタイリング | テクスチャが無数の顔パターンに置き換わっている | 異変とみなし引き返す。 |
| 通常の環境風の音 | 背後の足音を模したリズミカルな音 | 異変とみなし引き返す。 |
| 畳の自然な隙間 | 床の継ぎ目から血が滲み出ている | 異変とみなし引き返す。 |

**呪術学校の異変調査ガイド**のこの項目を活用すれば、単なる演出としての雰囲気と、ゲームのリセットを引き起こす本物の異変を正確に見分けられるようになります。

## ルートクリア、連続ループ、隠しエンディング

脱出を果たすには、一度の判断ミスもなく指定されたサイクルを連続して突破する必要があります。しかし、熱心な調査員たちによって、特定の異変には物語の深層に繋がる秘密が隠されていることが判明しています。

```
ループ0（基準状態の把握）
   ↓
ループ1〜7（標準的な巡回調査）
   ↓
ループ8（最後の正常ゲート） ───[ミス0回の場合]───> 真の夜明けエンド
   ↓（秘密の護符を回収した場合）
裏・封印の間エンド
```

### 完全制覇（真のエンド）の達成
正規の脱出エンドを迎えるには、サイクルカウンターが上限（難易度に応じて8または10）に達した状態で最後の境界を越える必要があります。最終ループで異変が存在しないことを確認した上で、堂々と前方の門を抜けて朝日の差す中庭へと進みましょう。

### 封印書庫エンドの解放条件
有志の検証により、1回のプレイ中に特定の3つの無害な異変と意図的に相互作用することで、別ルートの結末へ到達できることが判明しています：
1. 寮の廊下にある光る鏡を、すぐ引き返さずに直視・調査する。
2. 資料館でインクが滲み出る異変が発生している最中に、禁断の巻物を読む。
3. 敵対的な実体に接触される直前、猶予限界の1秒前で引き返す。

これらの条件を満たすと、最後の扉が地上の敷地ではなく、地下深くの封印の間へと接続されます。これらのハイリスクな裏ルートに挑戦する際にも、この**呪術学校の異変調査ガイド**をお手元にご活用ください。

## よくある質問（FAQ）

### 廊下で異変に追いかけられた場合はどうすればよいですか？
攻撃的な実体が出現した場合、細部を観察しようとしたり、すり抜けようとしたりしてはいけません。直ちに180度反転し、その廊下に入ってきた元の扉へ向かって全力疾走してください。無事に脱出できれば異変として記録され、現在のループカウントが維持されます。

### 廊下が完全に正常に見えたのにカウンターがリセットされたのはなぜですか？
見落とした異変が存在していたか、あるいは全く異変のない正常な部屋で引き返してしまったことが原因です。当**呪術学校の異変調査ガイド**を参照し、家具の配置が変わらないような微かな環境音の変化、反転した天井の垂木、掲示物の小さな文字の変化などを再確認してください。

### 同じループで2つの異変が同時に発生することはありますか？
標準ゲームモードでは、1つのサイクルにつき1つの異変のみが生成されます。ただし、高難易度設定やプレイヤーから報告されているナイトメアモードでは、環境の照明変化と実体の出現が重なるような「複合異変」が発生することがあります。

### この呪術学校の異変調査ガイドは音のみの異変にも有効ですか？
はい。本ガイドでは「3秒静止ルール」やオーディオのイコライザー設定など、具体的な聴取戦略を提示しています。これにより、環境の風音と、逆再生された鐘の音、幻覚の足音、引き戸の奥からの囁き声などの音響的異変を明確に区別することが可能です。
