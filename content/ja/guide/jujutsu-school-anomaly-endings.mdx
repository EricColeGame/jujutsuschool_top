## 呪術校の異変 全エンディング概要

どの周回プレイでも、プレイヤーの視覚的記憶と直感が試されます。学園は再帰的なループ構造を持っており、異変や穢れが存在する場合は報告するか引き返し、何もない正常な状態であればそのまま前進します。累計の正答率、呪具（レリック）とのインタラクション、そして解除した隠し封印の数に応じて、ゲームは5つの異なる結末へと分岐します。

呪術校の異変のエンディング一覧を紐解くと、日々の選択がどのように特定の結末へと繋がっているかが分かります。注意力を欠いた探索者への警告となるエンディングもあれば、教室の掲示板に散りばめられた難解な伝承の断片を繋ぎ合わせたプレイヤーにのみ用意された結末もあります。

| エンディング名 | 分類 | 難易度 | 主な解放条件 | 結末 |
| :--- | :--- | :--- | :--- | :--- |
| **終わりなき居残り (The Endless Detention)** | バッドエンド | 極めて低い | 異変の誤報告・誤判断を3回累積 | 無限に続く廊下のループに閉じ込められる |
| **盲目なる脱出 (The Blind Escape)** | ノーマルエンド | 低い | 呪具なしで8回連続で正しく進む | 学校から脱出するが、呪いは活性化したまま残る |
| **浄化プロトコル (Purification Protocol)** | グッドエンド | 普通 | 通常の異変をすべて浄化し第8ゲートに到達 | 校内が清められ、結界が安定する |
| **祓魔師の覚醒 (The Exorcist's Awakening)** | トゥルーエンド | 高い | 3つの隠し呪符を発見＋誤判断ゼロ | 根源の呪いが解かれ、永久に祓われる |
| **忘れ去られた呪術師 (The Forgotten Sorcerer)** | シークレットエンド | 極めて高い | 深夜の教室イベントを発生させ逆走ルートを完遂 | 創設者の暗黒の契約が明かされる |

コミュニティの報告によると、初見プレイヤーの多くが「終わりなき居残り（The Endless Detention）」を迎えています。これは、視覚的な歪みの多くがレトロな校舎の風景に違和感なく溶け込んでいるためです。通常の環境オブジェクトと超自然的な現象を見分ける技術を身につけることが、攻略において最も重要なスキルとなります。

## 攻略チャート：ノーマルエンドとバッドエンド

複雑な隠し儀式に挑む前に、まずは基本的な失敗条件と標準的な脱出ルートを把握しておく必要があります。これらの基礎ルートを通じて、ゲームの移動サイクルを学び、観察力を養うことができます。

```
[開始地点の廊下] 
       │
       ├── (誤判断3回) ─────────────────> エンディング1：終わりなき居残り
       │
       ├── (呪具なしで8ループクリア) ──────> エンディング2：盲目なる脱出
       │
       └── (全浄化＆アイテム収集) ────────> グッド／トゥルーエンドへ分岐
```

### エンディング1：終わりなき居残り（デフォルトのバッドエンド）

「終わりなき居残り」は、異変の判断を誤った際のペナルティとして発生するエンディングです。各廊下エリアは「正常」か「異変あり」の2択です。異変があるのに前進したり、正常であるにもかかわらず階段へ引き返したりすると、穢れ（侵食度）メーターが上昇します。

* **発生条件：** 1回のプレイ中に進行方向の誤った選択を累計3回行う。
* **主な視覚的兆候：** 廊下の照明が赤く点滅し、ロッカーが激しくガタつき、出口の扉を開けても再び1階へと戻される。
* **結末：** プレイヤーキャラクターは2年B組の誰もいない机に座り込み、這い寄る影の蔦に完全に呑み込まれる。

### エンディング2：盲目なる脱出（標準のノーマルエンド）

校内の伝承やオブジェクトを詳しく調査せず、8回連続で廊下を正しく進むことだけに専念した場合、最も到達しやすいのが「盲目なる脱出」です。

* **発生条件：** 隠された封印や壁の呪印を無視したまま、方向の選択ミスを一切せずにループ8に到達する。
* **重要な手順：** 最後の出口の扉に到達した際、校長室前の展示ケースを調べず、そのまま中庭へ直行して脱出する。
* **コミュニティ情報：** 実績解除を目指すスピードランプレイヤーの間では最速クリアが可能なルートとされており、最適化された進行であれば7分未満でクリア可能です。

| 判断ポイント | バッドエンドへの行動 | 通常脱出への行動 |
| :--- | :--- | :--- |
| **蛍光灯の点滅** | 点滅を無視して直進 | 直ちに引き返す |
| **鏡の反射の遅延** | 単なるラグと思って直進 | 階段を下りて引き返す |
| **1年A組の机のズレ** | 出口に向かって前進 | 引き返してフロアをリセット |
| **ループ8の中庭の門** | 誤った方向へ進む | 両開きの出口扉を押し開ける |

## グッド＆トゥルーエンディングの解放手順

より上位のエンディングを解放するには、単に異変を回避するだけでなく、校内の呪具やレリックと能動的にインタラクトする必要があります。呪術校の異変における最上位のエンディングを目指すなら、受動的な回避から積極的な調査へとプレイスタイルを切り替えなければなりません。

### エンディング3：浄化プロトコル（グッドエンド）の到達条件

グッドエンドに到達するには、中庭の正門から脱出する前に高レベルの呪いを祓う必要があります。これにはループ4の職員室で見つかる「儀式のチョーク」を使用します。

1. **浄化のチョークを確保する：** ループ4で職員室のホワイトボードを確認します。異変が発生していなければ、チョーク受けを調べてアイテムを入手・保管します。
2. **床の呪印を特定する：** ループ5から7を進む際、リノリウムの床面を念入りに調べます。異変による影の呪印が現れたら、引き返す前にチョークのアイコンを選択して直接浄化します。
3. **ミスなく浄化を完遂する：** 一度も判断ミスをすることなく、8つのループをすべてクリアします。
4. **最終ゲートでのアクション：** ループ8で門を開ける前に、中庭の敷居に残りのチョークを使用します。

### エンディング4：祓魔師の覚醒（トゥルーエンド）の解放条件

トゥルーエンドでは、学園の霊場を歪めていた元凶の存在が明らかになります。この結末を迎えるには、一切のミスを犯さない完全な立ち回りと、異変が生じた設備の中に隠された3枚の紙の呪符（お札）を収集することが求められます。

| 呪符名 | 必要ループ | 該当する異変の条件 | 詳細な出現場所 |
| :--- | :--- | :--- | :--- |
| **見通しの呪符 (Talisman of Sight)** | ループ2 | プレイヤーの動きを追う目のポスター | 保健室の掲示板の剥がれかけた角 |
| **束縛の呪符 (Talisman of Binding)** | ループ5 | トロフィー棚の下に伸びる逆向きの影 | 運動部展示ケースの背面パネル |
| **断絶の呪符 (Talisman of Severance)** | ループ7 | 逆回転する時計の針 | 割れた教室の壁掛け時計の内部 |

3枚の呪符をすべて集めると、廊下8に入った瞬間に不気味な儀式の鐘が鳴り響きます。通常の中庭出口の代わりに中央の廊下が左右に裂け、地下神社の入口が現れます。神社へ足を踏み入れ、石の祭壇に呪符を捧げることで真の祓魔カットシーンが再生されます。リアルタイムのパッチ情報、プレイヤー同士の議論、コミュニティで検証された異変のスクリーンショットなどは [the Steam Community](https://steamcommunity.com) の公式ハブで確認できます。

## 隠し分岐：忘れ去られた呪術師エンド

呪術校の異変のエンディングの中で最も複雑なルートは、現在の学園設立以前から存在する太古のオカルトの秘密にまつわるものです。「忘れ去られた呪術師（The Forgotten Sorcerer）」と呼ばれるこのシークレットエンドに到達するには、特定の時間的条件下で通常の進行ルールを意図的に破る必要があります。

全エンディング達成（コンプリート）を目指すなら、極めて稀な「真夜中の鐘（Midnight Bell）」の異変を見逃してはなりません。この異変は、セーブデータでノーマルエンドとグッドエンドの両方を達成した後にのみ発生します。

```
[通常のループ進行]
       │
       ▼ (ノーミスでループ6に到達)
[時計塔の音を確認] ────────── (00:00に鐘が鳴る) ──────────┐
       │                                                   │
       ▼ (通常ルート)                                      ▼
 [通常の出口]                                  [3年C組の教室を調査]
                                                           │
                                               [禁忌の巻物を回収]
                                                           │
                                               [後ろ向きでループ0まで戻る]
                                                           │
                                                           ▼
                                            エンディング5：忘れ去られた呪術師
```

### 隠しルートのステップ別チェックリスト

1. **ノーミスの進行状態を維持する：** ループ1から5までをノーミスで突破し、聴覚的な呪いによるダメージを一切受けていない状態を維持します。
2. **真夜中の鐘の音を聞く：** ループ6に入ったら、敷居のところで直ちに立ち止まります。重く響く寺院の鐘が3回鳴り響けば、隠しルートが開放された合図です。
3. **3年C組の教室へ向かう：** 廊下の異変を探す代わりに、3年C組へ向かいます。通常この教室は施錠されていますが、真夜中の鐘イベント発生中は扉がわずかに開いています。
4. **禁忌の巻物を回収する：** 教室内の儀式机を調べ、「創設者の巻物（Founder's Scroll）」を入手します。
5. **逆走（バック歩行）で戻る：** 決して前進してはなりません。これまでクリアしてきた廊下を、後ろ向き（バック歩行）でループ0まで戻る必要があります。この逆走中に壁の異変に触れてしまうと挑戦は無効となり、即死シーケンスが発生します。

| 手順 | 目標 | 回避すべき危険 | 成功の判定サイン |
| :--- | :--- | :--- | :--- |
| **ステップ1** | ループ1〜5をクリア | 確認を怠って急いで廊下を進む | 各フロアで不審な音が一切ない |
| **ステップ2** | 真夜中の鐘を聞く | 音を聞く前に移動してしまう | 特徴的な低周波の寺院の鐘の音 |
| **ステップ3** | 3年C組へ入室 | 廊下のロッカーに触れる | ドアがわずかに開き紫色の光が漏れている |
| **ステップ4** | 創設者の巻物を入手 | 教室内に長居しすぎる | インベントリ取得確認アイコンの表示 |
| **ステップ5** | ループ0まで逆走 | カメラを前に向ける（前進する） | 夜の正門入口に到達する |

## 異変検出の戦略とスピードランのコツ

呪術校の異変で複数のエンディングを安定してノーミスクリアするには、場当たり的な確認ではなく体系的な索敵が不可欠です。熟練の異変ハンターたちは、各廊下を「近景要素」「建築構造」「音響・空間シグナル」という3つの視覚レイヤーに分けてスキャンしています。

### 3層スキャンテクニック

* **レイヤー1（足元・至近距離）：** 開始地点から5メートル以内にあるロッカーの取っ手、床タイル、天井の蛍光灯などを点検します。
* **レイヤー2（中距離の設備）：** 教室の表札、壁のポスター、掲示板のプリント、消火器の配置などを確認します。
* **レイヤー3（遠景・音響）：** 逆再生される足音や壁の向こうの不規則な呼吸音に耳を澄まし、廊下の奥の出入口に不自然な影の歪みがないかを注視します。

| 異変カテゴリー | 微小な変化（見落としやすい） | 明らかな変化（一目瞭然） | 正しい対処法 |
| :--- | :--- | :--- | :--- |
| **構造の異変** | 廊下の幅が約5%狭くなっている | 床タイルが抜け落ち無限の虚無が広がる | 直ちに180度反転して引き返す |
| **文字・テクスチャ** | ポスターの漢字が左右反転している | ポスターが血の手形に置き換わっている | 直ちに180度反転して引き返す |
| **音響の異変** | 足音のエコーが0.5秒遅れて響く | プレイヤーの名前を呼ぶ囁き声が聞こえる | 直ちに180度反転して引き返す |
| **実体（怪異）** | すりガラスの奥に微かな人影が立っている | 怪異の全身が廊下を猛ダッシュしてくる | ダッシュせずに静かに引き返す |
| **正常な廊下** | すべてが基準状態と一致している | 歪みや音声ノイズが一切ない | 落ち着いてそのまま前進する |

これらの観察ポイントを押さえることで、致命的な誤判断を防ぎ、目的のエンディングへと確実に到達できるようになります。

## よくある質問（FAQ）

### 呪術校の異変には全部でいくつのエンディングがありますか？

現在確認されている主要なエンディングは全5種類です。「終わりなき居残り（バッド）」、「盲目なる脱出（ノーマル）」、「浄化プロトコル（グッド）」、「祓魔師の覚醒（トゥルー）」、そして「忘れ去られた呪術師（シークレット）」です。各エンディングには固有のクリア後カットシーンが用意されており、プレイヤープロフィールに対応する実績が解放されます。

### トゥルーエンドを目指している途中で異変を見落とすとどうなりますか？

異変を見落として前進してしまうと、「完全クリア（ノーミス）」の条件を満たせなくなります。集めた呪符のカウントはリセットされ、その周回では地下神社への通路が永久に閉ざされるため、バッドエンドかノーマルエンドのいずれかに強制分岐します。

### 初回プレイでシークレットエンドを解放することはできますか？

いいえ、不可能です。プレイヤーの検証およびゲーム内フラグにより、「忘れ去られた呪術師」に必要な「真夜中の鐘」イベントは、セーブデータ内にノーマルエンドとグッドエンドの両方のクリア実績が記録されていないと発生しないことが判明しています。まずは前提となるそれらのルートをクリアしてから、3年C組の秘密の巻物を探しに行きましょう。

### 校内の廊下で最も見落としやすい異変は何ですか？

最も見落とされやすいのは、2階トイレの窓に映る「鏡像の遅延」です。最初の2秒間はプレイヤーの姿勢を正確に映し出しているため、振り返った瞬間に鏡像が動かないことに気づく前に通り過ぎてしまうプレイヤーが多くいます。反射する面を確認する際は、必ず3秒間立ち止まって観察するようにしてください。
