## 基本ルール：学園における異変の仕組み

ゲームの基本的なプレイループは、鋭い知覚と記憶の正確性を軸に展開します。学園の廊下を通るたびにシステム側で確率判定が行われ、廊下が完全に正常な状態（ベースライン状態）のまま維持されるか、特定の異変が1つ発生するかが決定されます。膨大な異変リストをチェックする前に、まずは「正常な初期状態」の配置を完璧に把握することが最も重要な武器となります。

環境を分析する際は、異変ゲームにおける鉄則を常に忘れないでください：
* **異変がない場合：** そのまま前方の出口ゲートをくぐり、クリア目標に向けてカウントを進めます。
* **異変を発見した場合：** 即座に180度振り返り、入ってきた扉から引き返すことで異変の検知を確定させます。
* **誤った判断へのペナルティ：** 異変が発生しているのに前進したり、正常な状態なのに引き返したりすると、進行カウンターは即座にゼロへリセットされます。

```
[ループ開始] ──> [廊下を観察] ──> [異変はあるか？]
                                      ├── YES ──> [引き返す] ──> [カウンター前進]
                                      └── NO  ──> [前進する] ──> [カウンター前進]
*(ミスするとカウンターが0にリセット)*
```

攻略効率を最大化するために、視認性の高さと危険度に応じて異変を優先度付けしておきましょう。分類は以下の通りです：

| 異変クラス | 発見難易度 | 音の手がかり | 主な発生場所 | リセット危険度 |
| :--- | :--- | :--- | :--- | :--- |
| **構造・建築の変化** | 低〜中 | ほぼ無し | 壁、天井、扉 | 中 |
| **物体・小道具の変化** | 中〜高 | 無し | 机、ロッカー、ポスター | 非常に高い |
| **超自然的存在** | 非常に低い | 頻繁にあり | 廊下中央、角 | 致命的（ジャンプスケア） |
| **聴覚の歪み** | 高 | 常時あり | 空間ステレオ音響 | 高 |
| **文字・標識の異常** | 高 | 無し | 非常口表示、名札 | 高 |

## 視覚および環境系の呪術学校の異変一覧

通常のプレイにおいて遭遇する異変の大半は視覚的なものです。これらの異変は、学校の日常的な構造物、教室の備品、廊下に散らばる呪術関連の小道具などを改変します。これらの変化は一切音を伴わないため、プレイヤーの報告でも視覚チェックには徹底した規律が必要であることが強調されています。

廊下を進む前に、まず入口の敷居で立ち止まり、天井から床までを見渡してください。特に、お札や神社の幟（のぼり）、掲示板といった呪具・関連オブジェクトには細心の注意を払いましょう。多くのプレイヤーが、掲示板の文字のわずかな入れ替わりや、ポスターの人物の視線が変わっていることを見落としただけで連続記録を途切れさせています。

| 異変ID | 視覚的な現象 | 正常な基準状態 | 検証のコツ |
| :--- | :--- | :--- | :--- |
| **ENV-01** | ロッカー4番のお札が上下逆さま | お札は赤い文字で下向きに貼られている | 進入直後にロッカーの列を確認する |
| **ENV-02** | 左側の壁に見知らぬ教室のドアが追加 | 廊下の教室のドアはきっかり2つ | 毎ループ左から右へドアの数を数える |
| **ENV-03** | 赤く点滅する蛍光灯 | すべての天井照明が安定した昼光色で点灯 | 歩き出す前に天井の継ぎ目を見上げる |
| **ENV-04** | 窓越しに見える黒板に血の混じった漢字 | 黒板には通常のチョークの図解のみ | 教室の窓ガラス越しに中を覗き込む |
| **ENV-05** | 壁のくぼみにあるウォーターサーバーから黒い汚泥が漏出 | 青いボトルが満たされた清潔な給水器 | 水受けトレイと床の反射をチェックする |
| **ENV-06** | トロフィーケースの横に立つ人体模型 | トロフィーケースの両脇には木製ベンチのみ | 右側の廊下の遠近感を確認する |
| **ENV-07** | 廊下のフローリングが畳に変化 | 標準的なワックスがけされた板張り床 | 足元の床のテクスチャを直接スキャンする |

この**呪術学校の異変一覧**の視覚セクションを頭に入れておくことで、焦りによる凡ミスを防ぐことができます。少しでも違和感を覚えたら、挑戦開始時に確認した初期の正常な状態と見比べてみましょう。

## 聴覚および実体（エンティティ）系の異変

視覚的な異変が記憶力を試すものであるのに対し、聴覚や実体系の異変はプレイヤーの胆力を試します。[Steam心理的ホラー一覧](https://store.steampowered.com/tags/en/Psychological%20Horror/)にあるような作品と同様、サウンドデザインは単に雰囲気を醸し出すだけでなく、極めて重要な攻略要素として機能しています。

実体系の異変は、幽霊のような生徒、蠢く呪霊、視界の端に佇む影のシルエットとして現れます。静かな小道具の変化とは異なり、これらの脅威には素早い反応が求められます。リズミカルな囁き声が聞こえたり、廊下の突き当たりに佇む人影が目に入ったりした場合は、絶対に近づこうとしてはいけません。

| 実体 / 音の手がかり | 感覚的な兆候 | 行動パターン | 推奨される対処法 |
| :--- | :--- | :--- | :--- |
| **忍び寄る追跡者** | 背後から近づく重く湿った足音 | プレイヤーと同じ速度で追従 | 振り返らずに即座に引き返す |
| **呪いの囁き** | 左耳から聞こえる低周波の詠唱 | ロッカー付近に固定された音源 | 入口の扉へと後退する |
| **影の少女** | 出口に微動だにせず立つ黒い人影 | 完全に静止、ライトを当てると消失 | 出口に近づかず、反転して戻る |
| **ガタつくロッカー** | 廊下の先で突然響く金属の激しい揺れ | 中間地点を通過すると発生 | 異変として記録し、入口へ戻る |
| **鐘の音の異変** | 学校のチャイムではなく神社の鐘の音が鳴る | 入口の扉を開けた瞬間に1回再生 | 即座に180度反転する |

コミュニティの検証によると、実体がプレイヤーを追い詰めて直接ゲームオーバー画面に持ち込むケースは稀であり、むしろ「その存在自体が異変である」という仕様になっています。実体に触れようとすると、ほぼ確実にパニックを誘うジャンプスケアが発生して連勝記録が無効化されます。焦るプレイヤーを欺きやすいため、決定版の**呪術学校の異変一覧**でも特に警戒すべき項目として挙げられます。

## エリア別観察チェックリスト

当てずっぽうに頼らずこの試練を突破するには、航空機のパイロットのようなチェックリスト方式を採用するのが効果的です。同じようなループを何度も繰り返すと認知疲労が生じ、廊下を駆け抜けがちになります。廊下を明確な視覚ゾーンに分割することで、1ループあたり10秒未満で死角なく確認できるようになります。

```
ゾーン1: 進入敷居 ──> ゾーン2: 掲示板＆ロッカー ──> ゾーン3: 窓 ──> ゾーン4: 出口ゲート
```

毎回のループで、以下の4ステップの索敵ルーティンを実践してください：

1. **ゾーン1（敷居と天井）：** 敷居を越えた直後で停止。蛍光灯の色味を確認し、ぶら下がっている物体や天井の変色がないかをチェックします。
2. **ゾーン2（掲示板とロッカー）：** 3歩前進。ポスターの文字の反転、顔の変化、またはコミュニティ共有の**呪術学校の異変一覧**に記録されているお札の消失がないかを確認します。
3. **ゾーン3（教室の窓と床）：** すりガラス越しに横目を向けます。暗い教室内に人影が立っていないか確認し、床板に足跡がなく清潔なフローリングのままであるか確かめます。
4. **ゾーン4（出口ポータル）：** 出口ドアの上にある光る非常口誘導灯を確認。走る人物のピクトグラムが正しい方向を向き、標準的な緑色で点灯しているかチェックします。

| セクター | 重点検査対象 | よくある誤認（偽陽性） | 推定スキャン時間 |
| :--- | :--- | :--- | :--- |
| **セクターA: 入口** | ドアノブ、足拭きマット、天井照明1基目 | 通常の照明のうなり音 | 2秒 |
| **セクターB: 収納** | ロッカー番号、南京錠の向き、傘 | 通常の網目が落とす影 | 3秒 |
| **セクターC: 教室** | カーテン、机、窓の反射 | モニターの標準的な映り込み | 3秒 |
| **セクターD: 最奥** | 非常口の文字、消火器、ゴミ箱 | 軽微なテクスチャ圧縮の乱れ | 2秒 |

集約されたプレイヤー戦略によると、この体系化された**呪術学校の異変一覧**に基づく点検方法を忠実に守ることで、無駄なリセットを80％以上削減できるとされています。

## 上級者向け設定と特定テクニック

微細な異変を発見できるかどうかは、反射神経よりもハードウェアの設定や視認性の明瞭さに左右されることが少なくありません。ポスターの視線がわずかに左に動くといった細かな変化は、モーションブラーが有効だったり画面のガンマ値が暗すぎたりすると、見抜くのがほぼ不可能です。

知覚能力を最大限に高めるために、以下の設定の最適化を行ってください：

* **モーションブラーとフィルム粒子を無効化する：** これらの映画風エフェクトは、壁のテクスチャや細かい文字の微小な歪みをぼやけさせてしまいます。
* **明るさ（ガンマ値）を調整する：** デフォルト設定よりわずかに明るく上げてください。影が濃いと、小道具のズレや床の模様の変化が隠れてしまいます。
* **ステレオヘッドホンを装着する：** かすかな呼吸音や時計の秒針音など、多くの異変は指向性のある音の手がかりを伴いますが、テレビやモニターのスピーカーでは聞き取れません。
* **移動速度を一定に保つ：** ダッシュは避けましょう。走ると空間異変のトリガー発生が遅れ、危険を認識する前に境界線を越えてしまう原因になります。

アップデートによる新パッチやランダムシードの変更に合わせ、自分自身の**呪術学校の異変一覧**を随時更新していくことで、新たに追加された変化にも不意を突かれずに対応できます。

## よくある質問（FAQ）

### ゲーム内には合計でいくつの異変が存在しますか？
正確な数はアップデートによって異なりますが、コミュニティの集計では現在、環境系、聴覚系、実体系を合わせて30種類以上のバリエーションが確認されています。検証済みの**呪術学校の異変一覧**を確認することは、実績解除を目指すプレイヤーが未発見の異変を特定するのに役立ちます。

### 自分のすぐ後ろに異変が出現した場合はどうすればよいですか？
扉をくぐった直後に背後から足音や呼吸音が聞こえた場合、振り返って確認してはいけません。入ってきた敷居をそのまま後ろ向きに跨いで戻りましょう。入口の扉へ引き返すだけで安全に異変判定が行われ、ループカウンターが進みます。

### 1回の廊下ループで2つの異変が同時に出現することはありますか？
いいえ。このジャンルの標準的な仕様に則り、1回の廊下サイクルには異変がゼロ（正常なループ）か、きっかり1つだけ発生します。明らかな変化を1つでも発見した時点で、残りの廊下を調べる必要はなく、安全に引き返すことができます。

### 異変を見つけたはずなのにカウンターがリセットされたのはなぜですか？
カウンターがリセットされる原因として多いのは、正常な基準配置を異変と勘違いした（誤認・偽陽性）場合か、引き返す前に出口側の判定ゾーンに近づきすぎた場合の2点です。異変リストにある明確な異変を発見したら、その場ですぐに引き返すようにしてください。
